# Superseded 2024 Rebalancing Schedule

## What the source states

One returned original page directly describes the superseded 2024 rule — `rebalance-old.txt` (page 1):

> 已废止的2024年历史规则：每个季度末重新平衡一次组合。这一规则只用于历史回测，不适用于2026年的实际组合。

Translation of the same passage:

- **Status:** the rule is labelled as the **abolished (superseded) 2024 historical rule** (已废止的2024年历史规则).
- **Mechanics:** the portfolio was **rebalanced once at the end of each quarter** (每个季度末重新平衡一次组合).
- **Scope restriction (retained):** this rule **is used only for historical backtesting** (只用于历史回测).
- **Applicability:** it **does not apply to the actual 2026 portfolio** (不适用于2026年的实际组合).

So, as described in that page, the superseded schedule was a quarterly cycle: one rebalancing at each quarter-end, historical backtest use only, explicitly excluded from the 2026 live portfolio [1].

## Uncertainty

The returned page does not state further procedural detail — e.g. which specific calendar dates count as quarter-end, any rebalancing tolerances or thresholds, transaction-cost handling, or which assets were rebalanced. The other admitted pages not returned by this query (redemptions, tracking, fees, and the remaining documents) remain unexamined here, so their contents are not addressed by this report.
