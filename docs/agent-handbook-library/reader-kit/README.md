# 读者离线练习包

这是一组自编的最小实验，不是 Agent 平台，也不依赖真实资料或模型。需要 Python 3，不安装第三方包，不联网，不写数据。固定的公开项目实操另见各册的版本和运行入口，不把这里的答卷冒充项目内置样例。

```bash
python3 lab.py admission
python3 lab.py source
python3 lab.py settlement
python3 lab.py grading
```

| 实验 | 先猜，再运行 | 怎样扩展 |
| --- | --- | --- |
| 知识库工具准入 | P‑1 是同空间的只读检索；P‑3 是编辑提出改稿，只进入待批准；P‑2 的空间不匹配，P‑4 的合同版本不受支持，P‑5 角色不符，P‑6/P‑7 参数格式不合格。 | 改出两个看似合理却不应执行的提议。把工作区换成用户的别名时，明确身份解析放在哪里；再为版本 2 写不同的字段校验，不能把新版本当成旧版直接接受。程序不会访问实际工作区，也不会写入。 |
| 有证据的政策问答 | 3 月 8 日，只有东区的 W‑17‑R1 可纳入当前政策证据。晚发布的修订、只搜到摘要、其它区域分别因不同原因被排除。入选不代表推理已经正确。 | 只把截止日期移到 3 月 18 日。此时两版都满足简单筛选；实现仍没有同源版本关系。用显式的替代关系决定应采用哪一版，不能只取最大的文档号。 |
| 运行结算复盘 | T‑202 通知已尝试但结果未知，不能补发；已保存正文不随之删除。T‑203 用户取消后不继续，已有正文可留存。T‑204 运行完成但没有正文，不算报告交付。 | 为每行补齐人或任务的操作授权、可核对的远端凭据标识（只写合成 ID）、读回动作和人工处理规则。这个小程序不执行任何操作。 |
| 独立判分 | G‑1 字节没变但日期错，G‑2 日期对但读回不是原字节，G‑3 数字和形状对但没有定位；只有 G‑4 通过机械初筛。 | 新增一个不空但指向错误材料的位置。机械初筛会过；写下人工复核要核对的原句、事实、适用范围和时间，再修正评分方法。 |

请复制数据再改，不需要改系统设置、开网络端口或填写 API 密钥。选一个反例写入你自己的用例库，比简单把分数相加更有价值。
