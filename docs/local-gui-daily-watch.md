# 每日追踪（Open 0.42 候选）

仅在受信任的单 Owner 在线研究工作台显示「每日追踪」。这里设置每天固定执行的**问题**，不上传 PDF、不设置数据源、不改变持有者、模型、搜索或 Wind 权限。浏览器不接收服务凭据，也不能自行指定收件人。本地离线 GUI 不启用此功能。

1. 写下要每天查看的问题，选择北京时间，保存。默认没有选定时刻，也没有勾选自动执行或邮件；保存本身不发请求。
2. 打开「启用自动执行」。部署操作员须单独设置服务环境 `ETF_GUI_DAILY_AUTORUN=1`，否则只保存设置。开启后，新的有效时间槽使用当前工作台的正常研究 Runtime 和同一调用账本，可能产生费用。每个追踪每天最多认领一个原始 Run；同一时刻的多个追踪在单 Owner Worker 空闲后依次进入。当天错过的槽在本地当天仍可执行，不补跑前几天或启用/更改前已经过去的时刻。
3. 可以修改问题、时刻或暂停未来运行。暂停不取消已经认领的本轮；如需停止在途 Run，从原会话取消。部署更改模型或其他运行配置后，旧追踪必须重新确认启用。
4. 追踪卡片列出最近 14 个日期记录。用「查看本轮对话」打开已确认的原始会话消息。旧结果继续保存在会话历史。不确定的启动或外部结果不能作为成功，也不会被定时器重新发送。冷启动只重读原有事实，不补建未知 Run。

## 对照上次结果

同一追踪在问题原样未改、运行权限一致时，用最近一轮可验证且已完成的原始报告（或已发布正文）作为基线。「基线」按钮打开那一轮的原始会话。失败、缺失或不可验证的轮次不会充当对照；若可读的成功轮次更早，界面显示实际对照日期。改写问题后开始新基线，即使后来改回旧文字也不继承旧轮次。升级前未绑定问题版本的记录仍显示在历史里，但不猜测其基线资格。

回答区分已证实变化、暂未证实变化、证据空缺，并指出重要数字对应的原文日期和口径。历史正文是待核对的资料，而非本轮证据或操作指令。长正文超出现有任务输入空间时，模型收到明确标注为截取的部分，原历史内容不变。这里只要求模型说明变化，不用文字或哈希猜测业务上的显著变化；“只在有实质变化时发邮件”不是当前能力。

## 可选邮件

邮件默认关闭。由操作员在 GUI 服务的私有环境中配置已验证的单一收件人：`ETF_SCHEDULED_SMTP_ENABLED=1`、`ETF_SCHEDULED_SMTP_HOST`、`ETF_SCHEDULED_SMTP_TLS`（`implicit` 或 `starttls`）、可选 `ETF_SCHEDULED_SMTP_PORT`、`ETF_SCHEDULED_SMTP_FROM`、`ETF_SCHEDULED_SMTP_USER`、`ETF_SCHEDULED_SMTP_PASSWORD`、`ETF_SCHEDULED_SMTP_VERIFIED_TO` 和 `ETF_SCHEDULED_SMTP_VERIFIED_TO_VERSION`。使用支持 TLS 1.2+ 的 SMTP 和主机证书验证，需要 Python 3（默认 `/usr/bin/python3`）。这些值不得写入 Git、浏览器、日志或 GUI 的 live config JSON。操作员须先核对收件人、发送账户授权及相关服务费用。

Owner 在卡片编辑时检查所显示的脱敏收件人并显式勾选；收件人或校验版本变化不继承旧确认。执行时只发送原有 Runtime 留存并校验的最终正文，不为邮件重新调用模型。邮件未发出、服务接收、结果未知与研究完成状态独立；`邮件服务已接收` 不是收件箱投递证明。结果未知时不自动重发。当前 GUI 不提供手动补发按钮；未发出也不会自动重试。真实 SMTP 上线前应在隔离账户中确认投递许可、DNS 和 relay 可用性。

持久项目目录必须保存 `gui-daily-watch/`、`scheduled-email/` 和原来的会话、Run 及账本。该功能不是多租户队列、高可用调度器或通用活动通知系统。

## 每日摘要（Resend 模式）

单 Owner 模式可改为**每天一封**摘要。操作员另外设置 `ETF_DAILY_DIGEST_ENABLED=1`、`ETF_DAILY_DIGEST_OWNER_ORIGIN=https://<已认证的工作台域名>` 和 `ETF_SCHEDULED_SMTP_PROFILE=resend-smtp`，配合上述可信 SMTP 环境。Resend 的中继主机需为 `smtp.resend.com`、用户 `resend`，并用已获批的发件地址和凭据。域名仅用于链接，需已启用真实访问认证；链接不授予权限。邮件配置不得从浏览器或项目公开配置填写。

在工作台先指定摘要发送的北京时间并打开「启用每日摘要」，再勾选要纳入摘要的追踪。追踪按自己的时间跑，摘要不会启动研究，也不会因某项尚未完成补发或重开模型。暂停一个追踪不会打开它；若仍纳入摘要，显示其当天实际状态。用已核验原始结果的私密链接查看正文；未完成、待运行、已失败、找不到可核验结果等按事实区分。摘要不附问题、报告原文、密钥或 URL 分享令牌。没有纳入追踪时不发送空邮件。

Resend 模式关闭逐项邮件，也不把之前逐项确认迁移为摘要确认。收件人或受信任链接域名变化需要重新确认；已冻结的旧投递不换号、不重发，结果未知也不会用新身份试发。收件箱是否实际收到，仍需单独验证。
