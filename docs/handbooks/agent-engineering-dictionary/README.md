# Agent 工程辞典

[下载 PDF](./agent-engineering-dictionary.pdf) · 352 页、320 个词条、27 个小类。

这是一份可按条目独立查阅的资料。每个条目有定义、适用条件、常见误区与验收方法，并附参考链接。书内含可点击的三级目录、术语索引和相邻条目。

- 基础、工具与方法：模型、系统提示词、结构化输出、Tool、MCP、Skill。
- 运行时与协作：工作流、状态机、会话、恢复、协作编排、渐进交付。
- 数据、知识与 RAG：文档解析、分块、嵌入、向量库、召回、重排和引用。
- 框架、服务与部署：模型网关、Agent 框架、存储、队列、配置、容器化和运维。
- 测评、观测与可靠性：评测集、测试、评分、Trace、诊断与回归。

这不是安装清单或时效性产品报价。具体版本、配置和服务可用性以官方文档为准。辞典内容不代表 Open ETF Agent 或任何单个实现包含全部功能。
