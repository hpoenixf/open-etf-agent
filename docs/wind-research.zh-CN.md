# 在研究项目中使用 Wind 基金工具

[English](wind-research.md)

独立命令 `wind:fund` 用来查单只 ETF 的场内日收盘。研究项目走的是另一条链路：Worker 把经过审核的 Wind 基金能力以多个只读工具提供给 Agent，Agent 可以为同一个问题选择不同工具。两者都不默认启用。

## 显式启用

在有效的 `research-project@1` 配置中增加：

```json
"windData": {
  "schemaVersion": "wind-fund-research@1",
  "approvedPublicQueries": true,
  "approvedResultUse": true
}
```

只有确认有权查询并在该研究流程中使用规范化结果时才开启。将 `WIND_API_KEY` 通过受保护的环境提供给 Worker，与模型网关密钥分开，不写入项目配置、提示词或示例。提交任务不会请求 Wind，Worker 首次需要时才发现账号提供的兼容工具。目录里能看到，不代表每条查询都有权限、一定有结果。

工具覆盖即时行情、K 线、分钟行情、基金产品档案、财务和分红、披露持仓、单位净值和业绩、基金规模和持有人汇总、管理公司档案以及按条件筛选。请求使用已审核的字段，不传整段聊天、凭据、附件或报告正文。此接入不开放个股、个人仓位或交易指令。

## 写报告时注意

场内收盘价、单位净值、IOPV、报告期和披露日不是一回事。已知基金代码时用对应查询工具，不再拿筛选代替。Wind 取回的记录要注明来源，但不能冒充已获取的原始文件、编造成编号引用。碰到查不到或无法核验的回包，说明限制，不补造数据，也不要当成零结果。原报告存储及来源规则保持不变。提交、执行和读回见[研究项目](research-project.zh-CN.md)。
