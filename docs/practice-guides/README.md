# Agent 实战手册：从一条需求到一份经得起核对的报告

一个会回答的 Demo 容易展示。更难的是：下一次换人、换资料，或者程序中途停了，成果还能不能复用、核对和交接？

这套三册手册用同一个教学案例贯穿三个工作阶段。它不是工具采购清单，也不要求先读完整技术书。每册都可以单独练，合起来则是一条从需求到验收的实践路线。

| 手册 | 你要完成的事 | 练习结束后留下什么 |
| --- | --- | --- |
| [01 · 把一次需求做成可复用的 Skill](01-reusable-skill.pdf) | 把一句需求拆成有边界、有输入、有检查方法的工作方法，再换一道题验证能否复用。 | 一张方法卡、一份输入和权限清单、一组可重复的验收题。 |
| [02 · 从搜索命中到可核对的研究结论](02-evidence-to-conclusion.pdf) | 从候选线索找到可确认的原文，逐条判断证据到底能支持什么。 | 一份主张—证据表、一段谨慎结论、一条能重新打开的核对路径。 |
| [03 · 从能跑到能交付](03-reliable-delivery.pdf) | 在取消、断开、重启和内容出错时，分清什么已经交付、什么还需要复核。 | 交付记录、可回读的版本、失败场景与复盘清单。 |

## 不知道从哪一册开始？

- 团队又来了一条和上次差不多的需求：从 **01** 开始，先沉淀做法，再决定要不要抽成工具。
- 模型给了一串链接，但你不敢引用它的结论：直接做 **02**，先审一条最重要的主张。
- 用户收到了报告，但你说不清能不能找回来、它对不对：直接做 **03**，先把交付与内容质量拆开验。

每册都包含任务、示例、动手步骤、失败变体和参考答案。三册共有的[合成案例 JSON](case-fixtures.zh-CN.json)可以直接复制到自己的练习目录，用来对照答案或扩展测试。示例材料为手册原创教学素材，不是真实基金资料、持仓或投资建议。固定项目演练以 [Open ETF Agent v0.48.0](https://github.com/hpoenixf/open-etf-agent/releases/tag/v0.48.0) 为准；使用公开离线演示和定向测试不需要模型密钥，首次安装锁定依赖可能需要联网。教学练习与公开版自带例子有意分开：不要把手册里的合成文件当成公开版的内置数据。

想了解设计来由，可读 [Skill 为什么不只是 Prompt](https://hpoenixf.com/eff-agent-article/articles/agent-skill-from-markdown-to-callable-research)、[从搜索到连续阅读](https://hpoenixf.com/eff-agent-article/articles/021-agent-web-research-from-search-to-deep-reading) 和 [为什么独立处理结果发布](https://hpoenixf.com/eff-agent-article/articles/019-agent-answer-publication)。这些是手册之外的延伸阅读，不是完成练习的前置条件。
