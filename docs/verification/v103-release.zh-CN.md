# v1.0.3：有数据依据的柱状图与饼图

[English](v103-release.md)

Owner 界面可以把明确的数值渲染成柱状图和饼图。数据可以来自用户提供的数值或已核验的来源；无效或缺失的图表数据不会替换正文。符合条件的公开网页读取超时时，可以返回不可用结果而不丢弃正文。

[固定实现](https://github.com/hpoenixf/open-etf-agent/tree/372c6143dd3e8547c01b96276c7c21f8e5d469d2) · [图表协议](../skills/financial-chart-user-data.md)

- 固定实现的离线测试 1,826 项通过、0 失败、6 项跳过。
- 预发浏览器在输入标记修复后显示了柱状图和饼图，并检查了无效图表的降级。证据不覆盖所有图表类型、图片导出带图或另一轮真实模型十题。
- 本版不包含私有测评工作台或预发专用数据库改动。
