## Boundaries that remain explicit

- The same Run retains its exact request, selected Grant/bindings, original absolute deadline and durable root budget. Unknown reservations are not refunded. Duplicate call IDs remain consumed across restart.
- A lease/fence rejects stale **DB commits**. It cannot undo or fence a remote service's side effect. File and database publication are not one atomic transaction.
- Only a completed, version-bound Child handoff is reconciled; incomplete or unknown child work is not automatically rerun. Its sources and scoped relationship are validated. Fixture Child is not evidence of live independent reasoning.
- Working-note persistence is not adoption. A committed adopted input is reread by identity before another dispatch. Forgetting still filters future typed Memory content.
- Memory result consumption verifies the original immutable revision and intent; it does not consume a fresh authorization. Interrupted writes with an old lock remain blocked.
- Report recovery reads the same artifact/revision and legacy file bytes. Orphan/unknown files require inspection; no generic automatic orphan deletion or arbitrary external reconciliation is promised.
- Unsupported active schemas and inconsistent groups/cursors are refused. Old immutable artifacts have a separate reader contract; there is no old active-Run migration shim.
- Trusted local JavaScript retains process privileges. Its selected module file is hashed; arbitrary closure state/dependency attestation, package marketplaces and sandbox isolation are not claimed.
- The CLI resumes only its known fixture binding. Genuine live recovery is unqualified; earlier v0.1–v0.5 live observations are not new v0.7 evidence. No live request was made for this phase.

## Node compatibility and licensing

The supported metadata floor is `>=26.8.1 <27`, not a claim that every allowed Node patch has been tested here. The user reported all v0.6 tests passing on 26.8.1; that is user-provided v0.6 evidence. This environment's actual v0.7 qualification uses 26.11.1. No extra Node binary was downloaded. The official [SQLite API history](https://nodejs.org/api/sqlite.html) places the synchronous database/statement APIs and read-only open capability before that selected floor; this code does not rely on 26.10's new `undefined` binding behavior. The pinned executable actually exercised the required API. A future Node release can change warnings or support status; that is not an excuse to invent another-version test result.

The user explicitly selected MIT during this work. The standard [MIT text](https://choosealicense.com/licenses/mit/) is used with copyright 2026 Huang Pengfei; package metadata is MIT and `private: true` remains. Third-party licenses/notices, including the vendored Kit, are unchanged. Historical earlier-phase license blockers remain historical. No tag, formal release or npm publication is performed here.

## Final qualification

The final frozen executable/test/fixture/lock inputs passed **249/249** tests, exit 0, about 29.28 seconds. This includes all twelve real-process interruption/cancel/deadline cases, ten independent Runtime negatives, thirteen Plugin tests, fifteen real SQLite cases, eight Memory adapter cases, seven CLI cases and thirteen scoped errno maintenance regressions, alongside the inherited suite. The exact input digest is in `v07-candidate-inputs.json`; a post-run comparison found no drift.

A separate ordinary directory began without inherited node_modules. Two `npm ci --offline` attempts failed with **ENOTCACHED** for the same original locked tarball; no build ran after those failures. They were cache misses, not network permission refusals. A subsequent normal official-registry `npm ci --ignore-scripts --no-audit --no-fund` installed the same 95 locked packages into a new engineering cache and exited 0. No install hook or dependency upgrade occurred. Independent build exited 0. Seventeen separate built-output commands then verified five durable profiles, nine real report receipts and the original fixed four-case denominator through **4/4 actual loopback HTTP checks**. Terminal resume did not change receipts or root usage.

Independent source/method-history review also reproduced two self-consistent forged payloads passing to a new Gateway despite valid Host originals. Both RED assertions now stop before dispatch after binding successful historical payloads to their original facts; all ten review assertions pass in the final aggregate. These corrupt-checkpoint tests are not a claim that SQLite is a cryptographically authenticated store.

The stable errno maintenance was imported without change from its reviewed public candidate. Normalization is local to the actual `mkdir`/`link` boundary, follows bounded causes or the exact native operation/path message, and still requires directory/byte postconditions. Unknown, mismatched, cancelled and null/undefined reasons do not become success. Its independent v0.6 suite had 184/184; the integrated v0.7 suite above is separate evidence.

The pinned original Evidence Kit's plan/apply lint, verify generation, drift check and verify-stage lint exited 0. Its final status records **6/6 tasks, provider-free completion** with the executable input digest and actual external-check artifacts. This structural view does not authenticate a test runner or assess model semantics. [Exact Kit results](v07-kit.safe.json).
