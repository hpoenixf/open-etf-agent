# v1.0.4: interactive research workspace and bounded concurrency

[简体中文](v104-release.zh-CN.md)

The owner GUI lists configured public research capabilities and allows explicit selection of the bundled market-hotspot, long-horizon and chart Skills. Nine validated chart types offer interactive tooltips; line and candlestick charts fit the data, while bars and area preserve the zero baseline. Bad chart inputs do not suppress the answer.

The server may opt into up to five independent owner conversations. One conversation remains serial. For the supported OpenCode Go owner route, three minutes without genuine provider progress aborts only the local transport and releases the corresponding local slot after durable verification. A heartbeat is not progress. Unknown execution and billing remain unknown and are not replayed. This does not change provider quotas.

Tencent Yuanbao SearchPro MCP is opt-in, with a 90-second call cap and a 2 MiB response cap. Only bounded discovery hits are projected; the original source must still be read before citation. An isolated real search returned ten hits; the extended size bound was separately exercised by fixtures. Existing search configuration is not migrated or replaced.

- Ten distinct real-provider tasks in two waves of five using OpenCode Go glm-5.3-flash completed and independently read back the original published bodies. Ten physical requests, ten logical tasks. Runtime and delivery, not financial accuracy. Earlier different-source observations are not pooled into this cohort.
- Separate regression checks covered fifth/sixth admission, per-conversation seriality, non-replay, terminal unknown preservation, expiry and heartbeat/real-progress distinction, source/protocol refusal, bounded responses, and invalid-chart text fallback. The Stage browser verified manual Skill selection and reused saved area and combo chart entries to verify tooltips and keyboard dismissal without repeating model requests.
- Optional model failover, internal deployment overlays, the private evaluation workbench and Google/OpenAI account setup are outside this release.
