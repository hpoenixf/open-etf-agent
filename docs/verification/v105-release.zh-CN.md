# v1.0.5：从网页链接、PDF 单元格到计算图表

[English](v105-release.md)

研究工作台可以从受支持的静态网页链接打开含原生文本的 PDF，按物理页定位表格行列，把原始单元格引用直接交给受控数值计算。图表会保留原始物理页来源。没有可用表格时，仍可交付带页码引用的正文，不编数、不硬画图。缺日期、缺数据会显式保留；同一二进制关闭功能开关后，已保存的正文、来源和图表仍可读。

## 验证范围与限制

- 固定实现使用真实 Go 模型分两轮各跑五例，10/10 达标；新进程读回全部原始正文并校验字节一致，共 32 次物理请求，无未知项。首批的十项结果及 32 次请求均保留；该批未达标，不并入本批。这是运行时与交付验收，不评文笔或投资判断。[验收回执](v105-runtime-qualification.safe.json) · [固定源码](https://github.com/hpoenixf/open-etf-agent/tree/b8e7f235915c89434a58a67bd98eeef0ed4f1118) · [开关回退验证](https://github.com/hpoenixf/open-etf-agent/pull/68)。
- 真实网页到 PDF 的路径核对了第 2 页的两个不同单元格，图表保存了两条原始页链接；无可用表格的用例引用第 3 页正文、没有生成图表。其余覆盖网页引用、缺基期的计算、带日期的折线、柱图、饼图、堆叠图、非法图形数据降级和普通正文。预发浏览器另行验证了刷新后图表和引用依然可见。
- 网页读取仍遵守 robots 和重定向边界，不代表支持任意网页自动化、OCR、普通 HTML 工具直接打开裸 PDF URL，或执行任意 Python 代码。私有测评台和部署覆盖配置不属于本次源码验收。
