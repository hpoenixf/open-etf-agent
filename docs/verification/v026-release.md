## One module and its limits

The module is explicit, bounded public Web evidence acquisition. Approved static
HTML/UTF-8 text is normalized into immutable source pages while retaining original
bytes, URL/provenance and content identities. Existing Project, Result, Report,
Artifact and cold HTTP Reader consume those identities. Network policy retains
address validation, fixed destination, TLS validation, redirect, robots and
cancellation boundaries. See the usage document for the explicit controlled
platform profile and its limitations; a connector response is not product-network
qualification. This is not a browser, search service, autonomous crawler or
isolated Python module.

Necessary supporting adaptations are configurable frozen Project context, Web
page sizing, the existing Admission owner's explicit local unknown-slot release,
and general frozen report guidance. New pages use the 128 KiB profile, with old
page profiles retaining their original cold-read limits. New Projects default to
1 MiB of serialized context; old configurations retain their historical meaning.
The Gateway's separate 1 MiB request-body bound includes serialization overhead,
so context capacity is not a promise that every payload fits. Neither bound is a
model token window. A local slot release does not settle remote work or billing,
refund a request, authorize replay or clear provider rate limits. The separate
two-hour automation development is not part of this frozen Web execution source.
