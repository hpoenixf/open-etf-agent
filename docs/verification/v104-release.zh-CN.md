# v1.0.4：交互式研究工作台与有界并发

[English](v104-release.md)

Owner GUI 列出已配置的公开研究能力，可以手动选择热点解读、长期视角或金融图表 Skill。九类经过校验的图表支持浮窗。折线和 K 线贴合数据，柱图和面积图保留零基线。图表输入无效不影响正文。

服务端可以显式启用五路独立会话，同一会话仍串行。OpenCode Go Owner 路线连续三分钟没有真实模型进展时，仅停止本地传输，并在核实持久化记录后释放该本地占位。心跳不算进展。远端执行和计费仍记未知，不自动重发，不改变上游配额。

腾讯元宝 SearchPro MCP 是可选搜索源，整次上限 90 秒、响应体最多 2 MiB。搜索结果只作为查找线索，引用前仍读原始来源。隔离真实查询返回十条；扩容另用测试样本验证。不自动替换现有搜索配置。

## 证据与适用边界

- [固定集成源码](https://github.com/hpoenixf/open-etf-agent/commit/9c029e72a3e8e6c8d3e5a2c75137f930aa9bed7e) · [固定十题声明](v104-integrated-qualification.safe.json) · [前期图表协议与预发证据](https://github.com/hpoenixf/open-etf-agent/pull/58)。
- 使用 OpenCode Go glm-5.3-flash，分两组、每组五题。十个独立真实任务均正常完成并读回原始正文，共十次物理模型请求。核验的是 Runtime 和交付，不是模型金融结论；不同源码的既有观察不混入本轮分母。
- 独立回归覆盖并发上限、同会话串行、未知请求不可重放、静默超时、心跳和进展区分、非法源和响应、无效图表不吞正文。预发浏览器实选 Skill，并复用保存的面积图与柱线图验收浮窗和键盘关闭，不重复发请求。
- 模型备援、内部部署补丁、私有测评工作台和 Google/OpenAI 账户配置不属于本版本。
