# v1.0.4：扩展金融图表类型

[English](v104-release.md)

图表 Skill 补充二维热力图、同单位柱线联动图、多折线图、面积图及使用明确 OHLC 数据的 K 线图。只有图表工具可用时，可信系统提示才引导选图。前端只渲染校验通过的数据；图表缺失或无效时，不影响正文展示。

[固定实现和预发证据](https://github.com/hpoenixf/open-etf-agent/pull/58) · [图表协议](../skills/financial-chart-user-data.md)

预发浏览器使用合成数据和真实模型，验收了五类新增图表、柱线联动的键盘交互，以及刷新后读回仍保留缺值断点的面积图。该证据验证渲染和读回，不代表金融结论正确、完成了一轮新的固定十题付费测评，或正式环境已经部署。开源测评入口仍为 CLI，本次改动不包含私有工作台或服务器部署配置。
