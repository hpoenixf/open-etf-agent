# Atlas Notes (Version A) — Export and Offline-Use Conditions

_Source: synthetic Atlas guide, version A-2026-01 (pages 1–2). All statements below apply only to this synthetic guide._

## Export conditions

- **Free edition:** exports **CSV only**, limited to **at most 120 rows per export**.
- **Enterprise edition:** adds **PDF export** in addition to CSV.
- **Online requirement:** **all exports require an online connection**. Enterprise edition adds the PDF format but **does not remove the online-export requirement**.

## Offline-use conditions

- **Free edition:** can **view previously downloaded notes offline**, but **cannot edit them offline**.
- **Enterprise edition:** **permits offline editing**.
- **Online requirement:** the **initial download** and **all synchronization** require an online connection.

## Quick summary table

| Condition | Free edition | Enterprise edition |
|---|---|---|
| Export formats | CSV only | CSV + PDF |
| Export row limit | 120 rows per export | Not specified in this guide |
| Export needs online connection | Yes | Yes |
| View downloaded notes offline | Yes | Yes (offline editing also permitted) |
| Edit notes offline | No | Yes |
| Initial download / sync online | Yes | Yes |
