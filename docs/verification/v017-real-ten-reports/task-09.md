**Sources:** `atlas-a@A-2026-01:p2` (Version A-2026-01, page 2) and `atlas-b@B-2026-02:p2` (Version B-2026-02, page 2). Both documents are explicitly marked SYNTHETIC; the conditions below apply only to these synthetic guides.

## Stated Conditions (identical in both guides)

| Condition | Version A-2026-01 | Version B-2026-02 |
|---|---|---|
| Free edition: view previously downloaded notes offline | Permitted | Permitted |
| Free edition: edit notes offline | Not permitted | Not permitted |
| Enterprise edition: edit notes offline | Permitted | Permitted |
| Initial download requires online connection | Yes | Yes |
| All synchronization requires online connection | Yes | Yes |

## Comparison

Version A and Version B describe the *same* offline-use conditions, word for word, on their respective page 2. There is no substantive difference between the two versions on this topic:

- **Offline viewing:** Both allow the free edition to view notes that were previously downloaded, but offline access does not extend beyond content already downloaded.
- **Offline editing:** Both restrict offline editing to the enterprise edition; the free edition cannot edit offline.
- **Connectivity requirements:** Neither version offers an offline path for first-time content acquisition — the initial download needs a connection. Synchronization likewise always needs a connection in both versions.

## Takeaway

For these synthetic guides, the practical offline constraint is the same under both versions: you can read what you already have offline (free or enterprise), but you can only write offline with the enterprise edition, and any download or sync requires going online. Choosing between A and B would therefore have to rest on factors other than offline-use terms, which are not covered by the pages read here.
