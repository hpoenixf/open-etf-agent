# Atlas Notes Export Conditions Comparison

**Task date:** 2026-11-02 (America/Los_Angeles)  
**Sources:** Atlas Notes synthetic guide, versions A-2026-01 and B-2026-02, page 1 each.

## Comparison

| Condition | Atlas Notes A (A-2026-01) | Atlas Notes B (B-2026-02) |
|---|---|---|
| Free edition formats | CSV only | CSV and Markdown |
| Maximum rows per export | 120 | 300 |
| Online connection required | Yes, for all exports | Yes, for all exports |
| Enterprise edition addition | PDF export | PDF export |
| Enterprise effect on online requirement | Does not remove it | Does not remove it |

## Key takeaways

- **Formats:** B supports Markdown in the free edition in addition to CSV; A supports CSV only.
- **Row limit:** B allows up to 300 rows per export, versus 120 for A.
- **Connectivity:** Both versions require an online connection for all exports, including enterprise-edition exports.
- **Enterprise editions:** Both add PDF export, but neither removes the online-export requirement.
