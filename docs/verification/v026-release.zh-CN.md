## 一个模块及支持适配

本版主模块是显式、有界的公开 Web 证据采集：经批准获取静态 HTML/UTF-8 文本，
保留原始字节、URL/来源与内容身份，生成不可变分页，经原 Project、Result、Report、
Artifact 与冷启动 HTTP Reader 消费。地址全集校验、固定目标、TLS、重定向、robots
和取消边界保留；显式受控平台 profile 的限制见用法。连接器获取不冒充产品网络验收。
不提供浏览器、搜索服务、自主爬虫或隔离 Python 模块。

必要支持适配为冻结的可配 Project 上下文、Web 页大小、原 Admission 的显式本地
unknown 槽释放，以及通用报告指导。新页为 128 KiB，旧 profile 保留原冷读上限。
新 Project 默认 1 MiB 序列化上下文，旧配置保留原语义。Gateway 另有包含序列化
开销的 1 MiB 请求体限制，不能保证所有上下文都能装进请求；两者均不是模型 token
窗口。本地放槽不表示远端工作或账单已结算，不退款、不重放、不解除限流。另行开发的
两小时自动维护不属于这份冻结 Web 执行源。
