# v1.0.6：更可靠地读取网页链接中的 PDF 表格

[English](v106-release.md)

对已准入的原始 PDF 链接采用独立且有界的读取限制。表格中季度与年初至今列即使使用相同日期，也会分开处理，并保留明确的币种单位。版式歧义时不虚构单元格，仍可交付可读文本和物理页引用。普通网页与用户上传的限制不变。

本版范围是静态、带原生文本的 PDF。不新增 OCR、通用浏览器自动化或无界抓取，不包含定时任务或研究预算策略。

[固定运行时源码](https://github.com/hpoenixf/open-etf-agent/tree/69099abf273d5bbc5d82277b4769bc94f0316b65)。

## 验证

固定预发批次 10 道真实模型题全部通过，模型请求完成 58 次、未知 0 次。每题都回读并核对正文摘要值，验证物理页引用；需要表格原值或图表的题目也检查了相应产物。另有 6 项本地定向测试通过，覆盖真实财报和有界的大 PDF。本批真实题使用同一份财报，不代表所有 PDF 版式均已覆盖。[脱敏验收回执](v106-pdf-qualification.safe.json)。
