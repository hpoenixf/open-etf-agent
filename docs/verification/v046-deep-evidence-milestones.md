# v0.46 candidate: evidence milestones for Deep research

New Deep research runs show whether original-source checks have occurred, whether they returned usable source entries, and whether a readable answer or report was actually saved. Re-reading the same original entry does not increase the read count; one PDF page is one entry, not an entire reviewed document. A safely unavailable page produces neither a source claim nor forced extra work. Source acquisition and persisted output are not independent verification of the conclusion.

The Runtime adds conditional synthesis guidance to an existing next request only if it fits. It accounts for earlier capacity use before describing the last remaining Main round; it does not reserve new capacity or remove tools. The original tool admission, budget and Publication owners are unchanged. Original profiles in previously saved conversations retain their prior semantics.

Provider-free tests cover paired source and output receipts, normal Auto/Standard behavior, actual model-input shape, failure/cold readback, and identical tools across the transition. This candidate is not evidence of paid staging, a provider-internal thinking level, production deployment, multi-agent review, or a successful substantive research answer.
