- `atlas-b@B-2026-02:p1` — Atlas Notes synthetic guide, version B-2026-02, page 1

Both documents are marked **SYNTHETIC** and describe Atlas Notes export conditions.

## Comparison

| Condition | Atlas Notes A (A-2026-01) | Atlas Notes B (B-2026-02) |
|---|---|---|
| Free edition export formats | CSV only | CSV and Markdown |
| Maximum rows per export (free edition) | 120 | 300 |
| Online connection required for all exports | Yes | Yes |
| Enterprise edition addition | PDF export | PDF export |
| Does Enterprise remove online requirement? | No | No |

## Key differences
- **Formats:** Version B's free edition supports Markdown in addition to CSV; version A's free edition supports CSV only.
- **Row limit:** Version B allows up to 300 rows per export, compared with at most 120 rows in version A.

## Similarities
- Both versions require an online connection for all exports.
- Both versions' Enterprise editions add PDF export but do not remove the online-export requirement.
