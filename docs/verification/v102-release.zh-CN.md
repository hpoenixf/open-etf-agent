# v1.0.2 候选版验证范围

[English](v102-release.md)

[固定源码基线](https://github.com/hpoenixf/open-etf-agent/tree/1cb6999716858f71d77f916e7e210a3af4fa2d31)。本候选版补上按环境区分的 Jaeger 观测、已保存回答正文中的可点击引用，以及带水印、加大字号的 PNG 导出。测评对外入口仍是 CLI，私有测评工作台不随源码发布。

- Node 26.11.1：公开候选源码通过 26 项无供应商调用的检查；预发形态的集成通过 32 项专项和 15 项离线或合成入口检查。构建后的 GUI 提供已验证的加大字号模块。
- 先前已上线的 GUI 热修在浏览器里验证过公开引用可点击、可实际下载 PNG。展示层不改动已保存的原始回答。
- 独立启动的服务器运行时把预发环境的追踪写入服务器采集器，且追踪体现已确认的正文回读；这不代表正式环境已产生新的追踪。
- v1.0.1 的真实 CLI 验收只对应其固定 Runtime 源码。此处不宣称 v1.0.2 候选已做新的付费测试或已部署。
