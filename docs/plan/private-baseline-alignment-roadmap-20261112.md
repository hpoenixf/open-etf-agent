实施前固定对应 private 契约与源码、真实消费者、失败反例及受影响原回归。完成后检查公开用户的完整闭环、重启/取消/未知结果、权限与预算，再单独真实运行验收。不能把少量fixture、旧模型结果或相似名字作为完整对齐证明。相邻模块可共享既有底座，不能为了版本数把多个owner硬塞进同版。

0.29 聚焦普通消息、登记澄清、显式接续的完整 A02。Open 同 Run 澄清/恢复与 private 新 Run 接续的架构差异必须如实解释。0.30 聚焦 Child 独立取消、失败隔离、原结果消费恢复及受Root共享预算约束的父子生命周期；组合支持需逐项验明，不以串行两个文档示例宣称完整模块。
