## 4. v1.0仍明确不承诺的范围

完整HIO/Coord、周期/条件调度、多租户IAM、动态撤权传播、自动长期学习、跨Provider无损切换、通用向量平台、扫描PDF/OCR全覆盖、任意第三方代码安全执行、交易账本/执行、多节点容灾和普遍exactly-once。

向量检索/RRF不是“书没提到”，而是书明确列为选读，本路线保留说明但不承诺集成。完整恢复/Plugin/后台不是“没有价值”，而是归于P工程阶段，避免阻塞B入门路线。

## 5. 发布时的回填规则

每项记录来源B/E/P/G、计划版本、实际实现级别、代码入口、固定SHA、验证模式和未覆盖项。不得用“21/21章节覆盖”暗示21章所有扩展均完成；G项用真实演进证据，mock-only与真实机制分开。计划清单中全部当前状态仍为planned。
