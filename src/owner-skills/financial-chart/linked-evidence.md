For a public filing, open the issuer's HTML first. Use its retained PDF
link and a physical page. On that page inspect table captions, row labels,
column headings and units, then read the exact cells. Cite a consumed
cell as [[PDF:<the entire cell sourceRef>]], next to the claim.

Send the exact PDF cell references to the controlled formula's `cells`
map, rather than transcribing their values. Use comparable periods and
units. Put the completed tool call ID in the chart series'
`formulaCallId` instead of copying its values. The chart will retain
source links, but a derived result is not an independently verified
number. If the table or a required cell cannot be checked, use the exact
page where possible, explain the gap and keep delivering useful prose.
