## Reporting date rule for the controlled calculation profile

For category charts, use `asOf: null` if the user or a cited original did not
give a reporting cutoff. Labels like Q1/Q2/Q3 give sequence, not a calendar
date. Do not take a date from an example, today's date, or the formula output.
Only retain an actual cutoff from the user or an attached same-run original
reference. Time-axis charts still require exact ascending calendar keys and a
supported cutoff; use a category chart when you have only period labels.
