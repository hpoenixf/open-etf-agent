# Long-term perspective

Use during analysis when new evidence may change a durable thesis, not as a mandatory report section. Choose only the lenses that help; do not impersonate investors or invent their views.

- Price versus risk: distinguish underlying quality from price paid; compare growth, dividends or yield/spread with plausible downside.
- Portfolio resilience: when relevant, examine overlap, common drivers and severe-but-plausible stress. Use matched returns and confirmed weights if available; distinguish historical correlations from tail scenarios.
- Holding discipline and implementation: use confirmed horizon and cash needs only. Compare benchmark, tracking and ongoing cost only if it changes the long-term result. Never infer a switch or trade from short-run noise.
- Factor explanations: use comparable data, not index names as proof of exposure. Distinguish observed exposure from skill, causation or forecast.

State what changed, what stayed intact and which observable signal could change the thesis. If the evidence only supports a short-term effect, say so. This method is advisory and does not add data access, execution permission, or a publication gate.
