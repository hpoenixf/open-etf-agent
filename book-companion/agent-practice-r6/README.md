## 本轮新增什么

- 第五章：同一函数调用协议下，读取A/B、补读附录、返回工具结果并保存报告；合成回放默认离线，可选真实API适配器另需账户、模型和明确费用许可。
- 毕业练习：合成输入、任务卡、短报告和验收入口，覆盖正常、缺回答、诱导外发三场景。
- 第十七章：三份可实际阅读的短报告和来源，先人工判断，再汇总。
- 轻量配对与检索统一为Atlas，运行索引增加前置结果与期望总表。

统一推荐 Node.js 26.11.1。公开工程仍固定为 [v0.21.0](https://github.com/hpoenixf/open-etf-agent/tree/b22c43633101a10a50fc5b09ecc5ecba038f873a)，engines 为 >=26.8.1 <27；轻量练习只用内置能力，历史R5曾在24.19.0运行。推荐基线不是“最新LTS”声明。

本轮独立复核：旧9入口26次进程调用，22次预期成功和4次预期拒绝；新增协议10项检查通过；毕业三场景6轮完成、4轮等待、3轮拒绝；三篇人工文本判断汇总为1篇内容和来源同时通过。实际模型请求为零，真实API适配器只做本地模拟传输测试。没有新增跨平台、真实模型质量或15个工程入口的全量验证声明。

回放响应由作者编写，不是真实模型录制。毕业练习的免费180行/付费300行、更正优先级，以及配对练习的付费数值，都是各题单独增加的合成条件，不改写固定项目A/B原资料。各自来源目录随包提供。
