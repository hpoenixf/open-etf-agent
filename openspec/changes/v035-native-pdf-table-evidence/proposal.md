# v0.35 candidate: original native PDF table cells

Baseline: Open main `02044d16a69e564b636123dada6af596ceb1618e` (v0.34 A14
merged code; this change does not include its release packaging).

The existing PDF owner freezes original bytes and physical page text but
does not retain which table cell supplied a number. Two equal strings in
different columns or rows are not equivalent evidence. Add a complete
local research path from an admitted PDF to a reviewable report citation:
bounded page-local structure, exact cell acquisition through the normal
tool surface, and a cold report readback with the physical page, row,
column, unit, PDF digest and text location.

The design carries forward the original project’s distinction between
authorized original PDF data, an optional read-time table observation,
and semantic interpretation. It is an independent public implementation,
not a copy of the original product's source. No new dependencies,
approval modes, OCR, visual reconstruction, cross-page joins, remote
downloads, browser UI or claims about general answer quality.
