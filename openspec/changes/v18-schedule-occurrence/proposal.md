# Confirm one future occurrence without creating another executor

New module: Schedule Occurrence. This accepted v0.18 slice materializes one explicitly confirmed public synthetic task into an original Session Run. It extends the schema explicitly to opt-in schema5; it is not an upgrade or transparent compatibility claim. Historical roadmap v1.8 was only planned_candidate.

The complete loop is trusted confirmation → due/missed decision → atomic original Run link → existing Worker and optional original Admission → original Publication and Artifact Reader. A command must be invoked explicitly after restart. No daemon, automatic wake, cron/recurrence, billing or second executor is delivered.

Original v2/v3/v4 source, databases, paid receipts and default configuration remain distinct. Protected/ordinary/Child/Memory/PDF combinations are not added. Only same-scope code/tests/docs may be handed to the sole public integrator; no new paid invocation is authorized by this change.
