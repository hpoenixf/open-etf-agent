## Why

The Deep choice in v0.45 changes the intent and model guidance, but it cannot show whether work actually produced an original excerpt, only checked a source unsuccessfully, or delivered a readable answer. A model-generated progress assertion is not an effect receipt.

## What changes

- New Deep admissions, and Auto admissions whose original first Host effect selects Deep, use a revisioned milestone profile. Existing admissions retain their original revision and wire behavior.
- The Runtime derives progress and conditionally fits synthesis advice into its existing, persisted working input. The last-round advice follows the existing remaining Main/Root count after any optional compaction, and uses neither an extra reservation nor tool gating.
- The existing Progress and History views disclose safe, observed milestones from paired original-source receipts and actual delivery readback. Source retrieval, answer delivery and independent conclusion assessment remain distinct.

## Scope

This does not grant larger resource limits, add retries, select a provider, require an arbitrary tool-call minimum, score answer semantics, force output delay, disable authorized tools or add Child/reviewer admission. The supported evidence counters cover original public static web responses and original local document/PDF pages, not search snippets, derived calculations or a generic synthesis claim.
