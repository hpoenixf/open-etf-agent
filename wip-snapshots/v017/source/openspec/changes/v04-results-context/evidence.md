## Pre-implementation plan
The proposal/spec/tests precede product implementation. First run loadable ResultStore/Context/retrieval interfaces against behavioral assertions, not missing-import failures. Initial RED covers immutable source identity/rebinding even equal-text hashes, exact old-version reread after reopening, corruption/path rejection, whole paired-call groups and original question, oversized mandatory context, and query/scoped candidate behavior. Integration RED separately verifies actual Host registry replacement, child import/citation rejection, Gateway final encoded byte count and CLI candidate-driven read paths.

Serial existing Node 26.11.1; each permitted command at most 120 seconds, parent heap 512 MB. No service/live requests or new dependencies. npm cache/install and the inherited real MCP tests require the coordinated shared execution window; do not run while private validation owns it. Original logs stay local/ignored, observations are recorded only after actual terminal execution.

No v0.4 product test has run at creation. Earlier 71-test history is v0.3 only.
