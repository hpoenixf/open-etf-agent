# Artifact and reader contracts

1. Content bytes have SHA-256 identity; an Artifact ID binds content hash and exact supported format/media type. Immutable records never rebind an existing ID. Revisions bind a report, ordered attachments and actually acquired source snapshots; changing content creates a different revision while old IDs remain readable after reopen.
2. Only Markdown, HTML, CSV and SVG are supported. Markdown/HTML/SVG require bounded valid UTF-8 with format validation; CSV is produced from bounded structured rows by deterministic quoting. Formula-leading cells receive a documented apostrophe display transform. Preserve commas, quotes and embedded newlines. No arbitrary file paths from callers or models.
3. Stored metadata is not permission to follow arbitrary paths. Derive paths from validated IDs and formats; refuse static symlinks, unsafe ancestry, malformed records, size/hash/identity mismatch and missing artifacts. Registration is not a multi-file transaction: preserve explicit known partial effects and never falsely acknowledge a missing record/revision.
4. Source snapshots must pass the existing intrinsic source/hash validator. Derived notes cannot masquerade as original sources. A revision's report/attachments must be already registered and verified. Do not instantiate a second source truth or recovery mechanism.
5. The service binds only 127.0.0.1 and rejects foreign Host/Origin. GET/HEAD are the only read methods; IDs are strict, no arbitrary path/query or external redirect. HTML/SVG are attachment-only with nosniff and restrictive CSP; the index renders escaped metadata, never user report HTML. No scripts from documents execute in the reader page.
6. HTTP retrieval verifies exact bytes, SHA, media type and attachment IDs. Source-window retrieval is revision-bound. Observe stays metadata-only. Four-case evaluate always retains T1–T4, with not-run/failure states rather than reducing the denominator. No HTTP fetch can invoke a model or mutate the Run.
7. Preserve original legacy report.md/manifest readback while migrating Host save logic into one module. Initial save still has one attempt per Run. Explicit later revisions are immutable artifact operations, not automatic retries of unknown saves. Reopening stored bytes is not execution resume.
